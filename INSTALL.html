📦 doris-mcp-server Installation Guide

Version 1.3.1

Prerequisites

OSLinux x86_64
DorisCo-located with the MCP Server, FE port 9030, passwordless admin
PortDefault 3000

Installation (3 steps)

① Extract

tar xzf doris-mcp-server-1.3.1-linux-x64.tar.gz
cd doris-mcp-server

② Configure

Edit mcp-server.toml; usually no changes are needed. To change the port:

# mcp-server.toml
[server]
mcp_port = 3000     # your port here

③ Start

# Foreground
bash start-mcp-server.sh

# Background
nohup bash start-mcp-server.sh > /tmp/doris-mcp.log 2>&1 &

Seeing Uvicorn running on http://0.0.0.0:3000 means success.

First Launch

After logging into the WebUI with the Doris admin user, you can manually deploy the example workspace, which includes:

dw.orders12 example orders
dw.users5 example users
dw.products5 example products
dw.dim_date365-day date dimension

5 example metrics: total_amount, order_count, avg_amount, unique_users, user_count

The example is not deployed automatically; use the Admin-only button next to Reload to deploy it manually.

Verification

WebUI: open http://<IP>:3000/mcp/web in a browser and log in with admin:admin.

Agent: configure in Claude Code:

claude mcp add --transport http doris http://<IP>:3000/mcp \
  --header "Authorization: Bearer admin:admin"

Then ask "check the service health status" in the conversation to verify.

Common Operations

Stopfuser -k 3000/tcp
UpgradeStop → extract the new version over it → restart
LogsAudit log at ./logs/audit.log (path configured under [logging] in mcp-server.toml)
